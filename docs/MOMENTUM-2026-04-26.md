## Section 2 — Gamechanger Candidates (>200% growth signal)

### tursodatabase/turso (formerly limbo) — 18,370★
Pure-Rust SQLite rewrite, async-native, vector ext upcoming. Replaces both sqlite3 C lib and libSQL. **Integration path**: swap synapse `rusqlite` backend behind a feature flag `--features turso-backend`. Unblocks `BEGIN CONCURRENT` (Phase 2 SPEED-INTEL roadmap) without C-FFI WAL pain. Risk: API still beta; pin commits.

### cberner/redb — 4,457★
Pure-Rust ACID KV, zero-copy reads, no `unsafe`. Sled is officially stalling (last meaningful push 2026-04-04 only docs). **Integration**: replace any sled remnants in `synapse-core` (queue, side-tables) with redb. Single binary, no C deps.

### HelixDB/helix-db — 4,088★
Direct Synapse competitor: graph+vector in one Rust DB. Built from scratch, MIT-style. **Action**: bench against synapse on LoCoMo/LongMemEval; mine their HNSW+graph join for ideas; publish comparison in EVAL-HARNESS.md to stay ahead on integration story (synapse has CRDT+sign+session that helix lacks).

### huggingface/text-embeddings-inference — 4,749★
Rust+candle inference server, supports Metal, FlashAttention, batching. **Integration**: as embedder backend (alt to fastembed). Solves the ANE-not-exposed pain documented in synapse bench M7.

### slatedb/slatedb — 2,900★
LSM engine over object storage (S3/R2). Cloud-native data plane primitive. **Watch**: synapse single-node now, but slatedb is the "Pebble for object stores." Future multi-node tier.

### lightonai/next-plaid (ColGREP) — 390★ but freshly published
ColBERT-style multi-vector retrieval as agent grep. Tiny but technically novel. **Adopt idea**: multi-vector rerank stage in synapse turbo router (currently i8/f16/hamming → add late-interaction).

## Section 3 — Stack Recommendation (momentum-validated, 2026-04-26)

| Layer       | Pick                              | Rationale |
|-------------|-----------------------------------|-----------|
| OLTP store  | **turso (limbo)** + libSQL fallback | Pure Rust SQLite, async, BEGIN CONCURRENT, zero C-FFI |
| Side-KV     | **redb**                          | sled is dead, redb is the survivor; pure-Rust, ACID |
| Write-heavy LSM | **fjall**                     | RocksDB-class, no C++ link; for journal/queue |
| FTS         | **tantivy** (already wired)       | Battle-tested; quickwit consolidating ecosystem |
| ANN index   | **arroy** (mmap'd) + **usearch** (current) + **diskann-rs** when stable | mmap reduces RAM 50%; multi-index router already in turbo |
| Embed       | **fastembed** (current) → migrate to **text-embeddings-inference** for ANE | TEI exposes execution-providers fastembed hides |
| Compute     | **candle** (current) + **mlx-rs** evaluation | Metal native; burn for training-side only |
| Concurrency | **tokio** + **rayon** (current) + **dashmap** for shard-per-core | matches SPEED-INTEL Phase 2 plan |
| Cloud tier (v0.5+) | **slatedb**                | object-storage backend without re-architecting |

Drop / deprioritize: sled (dead), surrealdb-core (not on momentum table), any C-FFI sqlite wrapper once turso GA.
