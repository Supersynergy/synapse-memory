# Code of Conduct

We follow the [Rust Code of Conduct](https://www.rust-lang.org/policies/code-of-conduct).

Be respectful, technically honest, and specific. Harassment, threats, doxxing,
discrimination, and deliberate exposure of private data are not accepted in issues,
pull requests, discussions, or project events.

Report conduct problems privately to `security@supersynergy.de`. Maintainers may
edit or remove content, close contributions, or restrict participation to protect
contributors and users.
