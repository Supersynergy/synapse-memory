# Synapse v2.1 — M4 Max Extreme Spec

> End-to-end spec for making Synapse the fastest agent memory on Apple Silicon.
> Status: **in progress** · Date: 2026-04-24 · Branch: main · Backup: `backup-pre-m4max-bench-2026-04-24`

## 1 · Goal

Close the M4 Max gap identified in `M4_MAX_INTEGRATION.md`: every hardware resource (40-GPU, 16-ANE, 128 GB unified, NEON i8/b8) shall have a concrete integration.

## 2 · Success criteria

| Metric | Baseline v2.0 | v2.1 target | Stretch |
|---|---|---|---|
| `put` 1 doc (embed+index+fts) | 335 ms | **70 ms** | 15 ms |
| `search` p99 hybrid 100 k docs | 3 ms | **< 1 ms** | 300 µs |
| `int8 matvec` 100 k × 384 | 1 284 µs | **325 µs** (✅ measured) | 200 µs |
| `hamming b8` 100 k × 384 | 661 µs | **248 µs** (✅ measured) | 150 µs |
| PutBatch 1 000 docs | 5 min | 30 s | **5 s** |
| total speed-up hot path | 1× | 5× | **33×** (✅ measured) |
