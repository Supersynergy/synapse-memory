## Was tun für echten Bench

```bash
# Option A: Download erlauben
ALLOW_BIG_DOWNLOAD=1 cargo test --features clip-jina -p synapse-multimodal -- jina_smoke

# Option B: open_clip installieren (kleineres ViT-B/32, 338MB)
uv pip install open_clip_torch -p ~/.venvs/synml
python3 bench_clip.py  # mit ~/Pictures/*.{jpg,png}

# Option C: hf_hub fixen für py3.14
uv pip install huggingface_hub --upgrade -p ~/.venvs/synml
# dann sentence-transformers clip-ViT-B/32 (~340MB)
```

Option B ist schnellste Lösung (<5min). `open_clip` hat `ViT-B-32` pretrained `openai` (338MB cached nach erstem pull).
